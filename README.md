# Recipe Manager

Консольная система управления рецептами: создание блюд, масштабирование порций и генерация списка покупок.

## Установка

```bash
git clone https://github.com/TimofeqKarpov/tp_hw2
cd tp_hw2
pip install -r requirements.txt
pytest
```

## Запуск тестов

```bash
pytest
```
